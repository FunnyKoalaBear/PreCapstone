Factory Tracker - static demo
=============================
Upload everything in this folder to Neocities, keeping the folder structure:

  index.html  orders.html  order.html  new-order.html  tags.html  simulate.html
  css/theme.css  css/base.css
  js/data.js  js/app.js

Start at index.html. It uses sample data only. Scans, new orders and tag links
are saved in each visitor's own browser (localStorage), never on a server.
"Reset demo data" in the top banner clears them.

This demo is separate from the Django app (no Python, no database).
