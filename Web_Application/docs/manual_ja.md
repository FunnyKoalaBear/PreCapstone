# 工程進捗管理 使い方

> 各画面のスクリーンショットは後から追加できます。この手引きは日本語のみです（画面右上の言語切替は、この手引きには影響しません）。

## このシステムについて

工場の各作業台に置いた読取端末が、箱に付けたタグ（RFID）を読み取り、「どの受注が、どの工程まで進んだか」を自動で記録します。パソコンのブラウザで開くと、進み具合・遅れ・出荷待ちを一目で確認できます。見るだけでなく、受注の登録やCSVの取り込み、コードの管理もできます（権限によって使える画面は異なります）。

## 言語を切り替える

1. 画面右上の「日本語」または「English」を押します。
2. 選んだ言語は次回も使われます。

**ヒント:** 最初は日本語で表示されます。

## ホーム（進捗マトリクス）

**用途:** 未完了の品目の進み具合を、納期の近い順に一覧で見ます。

1. 上のカウンター（作業中・待機中・外注中・一時停止中・未着手・滞留・納期遅れの受注・外注遅れ）を押すと、その条件の「進行中の箱」一覧が開きます。
2. 「進捗マトリクス」では、1行が1品目、横に並ぶ1マスが1つの工程です。左の列（製番・品名）は、横にスクロールしても動きません。
3. 行を押すと、その受注の詳細画面が開きます。
4. 絞り込み: 「状態」「得意先」「納期（から）」「納期（まで）」を選び、「納期遅れのみ」「現在の工程から表示」を必要に応じてチェックして「適用」を押します。
5. 件数が多いときは「さらに表示」を押します。

マスの見方（表の上の「凡例」にも同じものが出ています）:

| 表示 | 意味 |
|---|---|
| 点線の枠だけ（○） | 未処理: まだ何も始まっていない工程 |
| 緑に✓ | 完了: 終わった工程（先頭から続く完了済みは「✓ 数」にまとめて表示） |
| 青に▶ | 作業中: 社内で加工している工程 |
| 紫にトラック | 外注中: 外注先に出している工程（外注先のコードと名称つき） |
| 赤みのあるオレンジに‖ | 一時停止中: 一時停止された工程 |
| 太い黒枠と右上の三角 | 現在の工程 |

色だけでなく、記号と枠の形でも見分けられます。

**ヒント:** 「現在の工程から表示」にチェックすると、完了した工程を省いて、これからの工程だけが見えます。

## 受注一覧（4つのタブ）

メニューの「受注一覧」を開くと、上に4つのタブ（受注一覧・新規受注・取り込み・コード一覧）が並びます。選んだタブは画面のアドレスに入るので、更新しても同じタブのままです。受注の登録・取り込み・コード管理は、計画担当以上の権限が必要です。

### 受注一覧タブ（受注を探す）

1. 「検索」に製番・得意先・客先注文番号・品名・品番・図面番号などを入力します。
2. 「状態」と「並び順」（納期・新しい順・得意先）を選び、必要なら「納期遅れのみ」をチェックして「適用」を押します。
3. 製番を押すと詳細画面が開きます。詳細画面では、タイムライン・履歴の確認、指示書の印刷、実績の記録などができます。
4. 「CSV出力」で、今の条件の受注をCSVにできます。

**ヒント:** 表は枠の中でスクロールします。見出しの行は動きません。

### 新規受注タブ（受注を登録する）

1. 「得意先」を選びます。登録がなければ「新規得意先」に名前を入力します。
2. 「客先注文番号」「納期」「備考」を入力します。
3. 品目ごとに「品名」「品番」「図面番号」「改訂」「数量」「材質」「箱数」を入力し、必要なら図面ファイルを選びます。
4. 「工程順」で工程を順に選びます。外注の工程には外注先・計画納期・伝票番号も入れられます。同じ品番の前回の受注があれば「前回の受注から工程順をコピー」が使えます。
5. 品目が複数あるときは「品目を追加」を押します。最後に「受注を登録」を押すと、受注一覧タブに戻り、登録した受注が表示されます。

**ヒント:** 製番は自動で付きます（年月-連番、例: 2610-001）。あとから変更はできません。

### 取り込みタブ（CSVからまとめて登録する）

1. 「CSVファイル」を選びます。文字コードはUTF-8またはShift-JISに対応しています。
2. 登録されていない得意先も作りたいときは「新規の得意先を作成する」にチェックします。
3. 「ファイルを確認」を押すと「プレビュー」が出ます。エラーがある行は理由が表示され、エラーが1行でもあると何も取り込まれません。
4. エラーがなければ「取り込み」を押します。

CSVの列（1行目に見出しが必要です。名前はこのとおり英語で書きます）:

`customer, customer_order_number, due_date, part_name, quantity, material, notes, route`

- 1行が1品目です。得意先と客先注文番号が同じ行は、1つの受注になります。
- `due_date` は 2026-12-31 または 2026/12/31 の形で書きます。
- `route`（工程順）は `工程名:コード` または `工程名:コード:納期` を `|` で区切ります。例: `Material:00101|Lathe:00012|Plating:00131:2026-11-02`
- 品番・図面番号・改訂の列（`part_number`, `drawing_number`, `revision`）は、付けても付けなくても構いません。

**ヒント:** まず1〜2行だけで試すと、書き方を確かめやすくなります。

### コード一覧タブ（コードを管理する）

コードは5桁の数字で、社内・仕入先・外注先を表します（00000〜00099は社内、00100〜00429は外部）。作業指示書にも使われます。

1. 一覧は「検索」と「種別」（すべて・社内・外部）で絞り込めます。無効にしたコードも見たいときは「無効のコードも表示」にチェックします。
2. 追加: 下の「コードを追加」に、コード・名称・種別・備考などを入力して「コードを登録」を押します。種別は、コードの数字から自動で選ばれます（変更もできます）。
3. 変更: 行の「編集」を押し、直して「変更を保存」を押します。
4. 使わなくなったコード: 行の「無効にする」を押します。消えるのではなく無効になるので、過去の受注には残ります。必要なら「有効に戻す」で戻せます。

**ヒント:** 同じコードは二重に登録できません。

## 優先度

**用途:** 納期に間に合わなそうな箱を、リスクの高い順に見ます。

1. 上の「すべて」「納期遅れ」「緊急」「注意」「順調」のどれかを押すと、そのリスクだけに絞れます。
2. 「並び順」で、リスク・現在の工程・滞留時間を切り替えます。
3. 表では「残日数」「余裕日数」（残日数から、これから必要な日数を引いた値）「現在の工程」「滞留時間」「リスク」「理由」を確認します。余裕日数がマイナスなら間に合わない見込みです。

**ヒント:** 理由の欄に「外注 ○日遅れ」と出ているときは、外注先への確認が先です。

## 出荷

**用途:** 出荷できる品目の確認と、月ごとの納期遵守の確認をします（計画担当以上）。

1. 「出荷待ち」は、すべての工程が完了して、まだ出荷していない品目です。「検索」「得意先」「納期（から）」「納期（まで）」で絞り込めます。納期を過ぎたものには「納期遅れ」と出ます。
2. 実際に出荷したら、その受注の詳細画面で「出荷済みにする」を押します（間違えたときは「出荷を取り消す」）。
3. 「月別の納期遵守率」は、各月に出荷した品目のうち、納期までに出荷できた割合です。「検索」「得意先」「開始月」「終了月」で絞り込めます。

**ヒント:** 納期遵守率が下がった月は、同じ月の「分析」で遅れた工程を探します。

## 分析

**用途:** どの工程が計画より遅れているか、どの工程で待ち時間が長いかを探します。上の2つのタブ（作業実績・計画と実績）で、同じ絞り込み（開始日・終了日・得意先・工程・外注先）を使います。

### 作業実績タブ

1. 工程ごとに「件数」「完了数量」「不良数」「不良率」と、「平均加工時間」「平均待ち時間（直前）」が出ます。
2. 平均加工時間・平均待ち時間のうち最長の工程には「最長」の印がつき、行の色が変わります。表の上にも、最長の加工時間と最長の待ち時間の工程が出ます。

### 計画と実績タブ

1. 前の工程の完了日から数えて、計画（工程の計画納期）と実績（完了した日）の平均日数を比べます。
2. 「超過率」は、実績が計画より何％長いかです。10％を超えると「軽微」、30％を超えると「大」、60％を超えると「重大」と表示します。
3. 表の上に「最も遅い工程」と「遅い工程ワースト3」が出ます。「並び順」で「遅れが大きい順」を選ぶと、遅れの大きい工程が上に並びます。

**ヒント:** 同じ工程が毎回「大」や「重大」になるときは、その工程が全体の遅れの原因（ボトルネック）です。外注先で絞ると、外注先ごとの違いも見られます。

## 現場のスキャンと記録の流れ

1. 箱には1つのタグが付いています。タグと品目の組み合わせは、「タグ管理」で登録します（「タグを紐付ける」）。タグをなくしたときは「タグを交換」で新しいタグに替えられ、これまでの履歴は残ります。
2. 作業者は、作業台の読取端末にタグをかざします。読取端末は、その箱の「次の操作」を自動で記録します（材料は「入荷」、社内加工は「開始」→「完了」、外注は「外注出し」→「外注戻り」）。
3. 記録された内容は、そのままホームの進捗マトリクスや優先度に反映されます。
4. 紐付けのないタグは記録されません。同じタグを数秒以内にもう一度かざしても、二重には記録されません。
5. 間違えて記録されたときは、計画担当が受注の詳細画面の履歴から「訂正」で取り消せます。
6. 読取端末がなくても練習できます。管理者は「スキャンのシミュレーション」で、タグを選ぶと次の操作が表示され、「確定」で読取端末の代わりに記録できます。

**ヒント:** 読取端末の通信が止まっていると、進捗が更新されません。しばらく動きのない箱は、ホームの「滞留」で確認できます。

## 用語集

| 用語 | 意味 |
|---|---|
| 受注 | 得意先からの注文。製番（年月-連番）で区別します |
| 品目 | 受注の中の1つ1つの部品。1つの受注に複数の品目があります |
| 箱 | 部品を入れて運ぶ箱。1つの品目に複数の箱を使うこともあります |
| タグ | 箱に付けたRFID。読み取ると、どの箱かが分かります |
| 工程 | 作業の1段階（材料・加工・外注など）。並び順を「工程順」と呼びます |
| コード（外注先コード） | 社内・仕入先・外注先を表す5桁の数字 |
| ボトルネック | 全体の流れを遅くしている工程 |

## よくある質問

**Q1. 進捗が更新されません。**
A. タグが箱に紐付いているか（タグ管理）と、読取端末が動いているかを確認してください。ホームの「滞留」の数も目安になります。

**Q2. 受注を間違えて登録しました。**
A. 受注の詳細画面の「編集」で内容を直せます。工程順は、スキャンされる前なら変更できます。

**Q3. 「取り込み」で何も取り込まれません。**
A. プレビューのエラー行を確認してください。1行でもエラーがあると、全体が取り込まれません。直してもう一度アップロードします。

**Q4. 使わなくなったコードは消せますか。**
A. 消さずに「無効にする」を使います。過去の受注には残ります。

**Q5. 間違ったスキャンが記録されました。**
A. 計画担当が、受注の詳細画面の履歴から「訂正」で取り消せます。取り消した記録も履歴には残ります。

**Q6. 色が分かりにくいです。**
A. 進捗マトリクスは、色のほかに記号と枠でも状態を示しています。凡例を確認してください。

**Q7. 表が長くて見にくいです。**
A. 表は枠の中でスクロールします。見出しの行は固定されています。検索や絞り込みで件数を減らすこともできます。

**Q8. 見られない画面や押せないボタンがあります。**
A. 権限によって使える画面が異なります。受注の登録・取り込み・コード管理・出荷は計画担当以上です。必要なら管理者に相談してください。
